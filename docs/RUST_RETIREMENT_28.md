# Imported-solid editing, snapshot persistence and Rust UI acceptance

Source checkpoint after0.4.13; published package assets are unchanged.

## Correctness scope

- All master-backed Library copies use independent exact snapshot recipes, not
  only SDK extrusions. Unverifiable source history cannot replace the authoritative
  exact master. Capture never changes the working document.
- Recipe-less exact masters can enter certified native subobject editing.
- Conservative imported tolerance metadata is numerically qualified on an isolated
  copy, never admitted by raising the edit ceiling or suppressing a refusal.
- Snapshot-origin native edits record the successful exact result, preventing a
  later Save/reload from replaying against an opaque over-tolerance parent.
  Parametric recipe families and historical parsers retain their prior behavior.

No geometry is faceted, resampled or reconstructed during tolerance qualification.
Existing surfaces, 3D curves, pcurves, ranges and topology remain intact; only copy
metadata changes. Supported edges require stored3Dcurves, nondegeneracy and existing
SameParameter/SameRange. Full-range OCCT numerical checks cover both seam branches
and located endpoints; numerical margins remain inside the unchanged ceiling.
This is not a formal interval proof. Unsupported representations remain explicit
refusals. Exact-method validity and all output certificates still apply.

## Native and host evidence

Native Rust acceptance exercises imported-metadata box and located cylinder edits,
stateless/session parity and full COMMIT certificates. Loose-metadata inputs hiding
real curve/surface or endpoint gaps, unsupported flags and pcurve-only edges refuse
without writing output or publishing a handle. A collapse still refuses.

Producer mutations disabling preparation and copy isolation go assertion-RED.
Removing the stored3Dcurve guard causes a genuine runtime crash on its negative
fixture, not a compiler failure; restored production passes. A separate host
mutation restoring opaque-parent replay fails with the original tolerance refusal.

Actual SDK tests cover editing without source history, source preservation, exact
replay, save/reload and a second edit/save. Private real-file checks additionally
cover movement of previously refused solids, one Undo, Undo/Redo and exact native
project round trips; private input documents are not public fixtures.

Linux native qualification is required before staging the matching development
library. Native ABI4 and UI ABI1 remain unchanged. No new Windows runtime or
shipping-package acceptance is claimed. Full application validation and frozen
source/publication receipts are recorded separately from focused checks.
