## Next architecture boundaries

- Main: persistent unified document history/transaction coordination using the
  existing application core, with opaque host geometry payloads during migration.
- A separate editor-core lane: persistent shared TextField/editor ownership, not the
  old repeated-measurement replay protocol.
- AI/MCP: visible human-review integration, lifecycle testing and useful bounded
  plans; normal primitive activation remains a separate reviewed decision.
- Research: sustained native behavioral evidence, prioritizing remaining division,
  editing, transformation, surface and solid interaction cases.

Those work scopes keep application-core/model/history, editor/text fields,
automation/assistant UI and native research input separate. Global build/public
registration and final integration remain centralized. Metadata-only generations,
history positions and planning revisions must not masquerade as complete document,
selection or topology identities.
