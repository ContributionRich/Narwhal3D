These 96×96 PNG source icons were generated and contributed by the Narwhal 3D repository owner. They are licensed under **GPL-3.0-or-later**, the same licence as the Narwhal 3D project code. See the repository `LICENSE` file for the full terms.

The source filenames identify their intended command or command option. Runtime toolbar assets use the `narwhal-<command>.png` manifest names at 24×24 pixels. Run:

```bash
python3 scripts/build_toolbar_icons.py
```

The importer uses exact command-name matches plus a small reviewed alias table. It does not install icons for unavailable commands or guess ambiguous mappings.
