# Support

Narwhal 3D is an early preview. Save important work frequently and verify manufacturing output before production use.

## Bugs

Use the in-app **Bug Report** panel or the GitHub bug form:

https://github.com/ContributionRich/Narwhal3D/issues/new?template=bug.yml

The in-app panel saves locally, copies sanitized Markdown, and opens a browser form. It never uploads attachments automatically.

## Questions and feature requests

- Search existing issues first.
- Use a focused issue form when available.
- Keep one command or one behavior per issue.
- See [STATUS.md](STATUS.md), [ROADMAP.md](ROADMAP.md), and [docs/gaps.md](docs/gaps.md) before reporting a missing feature.

## Include

- Narwhal version and package type;
- operating system and display server;
- graphics hardware when the viewport is involved;
- exact commands and input sequence;
- expected and actual behavior;
- whether the issue reproduces in a new empty model;
- a minimal screenshot, log excerpt, or model only after privacy review.

Do not post secrets, private client models, personal paths, or confidential manufacturing data.
