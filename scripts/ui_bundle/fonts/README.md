# Unmodified interface fonts

- **Inter.woff2**: copied from the installed Blender source tree's
  `release/datafiles/fonts/Inter.woff2`. Copyright 2020 The Inter Project Authors
  (https://github.com/rsms/inter). SIL Open Font License 1.1, included in
  `OFL-1.1.txt`. Blender's `release/license/license.md` identifies this font/license.
- **Ubuntu-Light.ttf**: copied from `epaint_default_fonts` 0.36.2's bundled fonts,
  the welcome window's egui font source. Ubuntu Font Licence 1.0, included in
  `UFL.txt`. Original file and embedded notices preserved, not modified.

These are fonts only, not packaged Blender/egui runtimes. The matching files improve
text layout; browser and BLF/egui glyph rasterization are not asserted identical.
